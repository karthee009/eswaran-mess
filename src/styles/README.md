# Eswaran Idly Kadai CSS structure

- `variables.css` — fonts, design tokens, browser defaults.
- `shared.css` — shared buttons, section spacing, reveal utility, global layout and common animations.
- `Navbar.css` — top strip, logo, language switch, navigation and mobile menu.
- `Hero.css` — hero image, overlay, stamp and ticker.
- `Story.css` — Our Story section.
- `Menu.css` — meal tabs, search, dishes and menu cards.
- `Branches.css` — branch cards and directions buttons.
- `Reviews.css` — customer reviews section.
- `FunctionOrders.css` — wedding and function orders banner.
- `Contact.css` — contact links and actions.
- `Footer.css` — footer and mobile sticky action bar.

All stylesheets are imported from `src/main.jsx`. Keep `variables.css` and `shared.css` before the section stylesheets.
